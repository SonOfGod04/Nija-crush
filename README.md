# Naija Crush 🇳🇬

A Nigerian-themed match-3 game: 45 missions across Nigeria's regions and festivals, special candies (⚡ Pepper Power clears a row and column, 💥 Jollof Bomb clears a type and its neighbours), pop-up Pidgin cheers, sound effects and music, and an "Osheyyyy" bonus for leftover moves.

Single-file, no build step, no dependencies. Progress is saved in the browser (localStorage).

## Deploy on GitHub Pages
1. Create a new repository and upload `index.html` and this README.
2. Go to Settings > Pages, choose the `main` branch and the `/ (root)` folder, then Save.
3. Your game goes live at `https://<your-username>.github.io/<repo-name>/`.

## Play locally
Open `index.html` in any modern browser.

Get playing!
